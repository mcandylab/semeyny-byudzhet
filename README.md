# Семейный бюджет

Приложение на Nuxt 4. Для локального запуска нужны Node.js 22.22.3+ или 24.15.0+ из LTS-линеек и npm.

```sh
npm ci
npm run dev
```

Подключение к существующему Supabase задаётся в локальном `.env`. В новом клоне скопируйте `.env.example` в `.env` и укажите URL того же проекта Supabase и его ключ `publishable`. Nuxt читает эти значения на сервере. Для общего бюджета используется прежняя таблица `budget_snapshots`, поэтому SQL-миграции не нужны.

## Публикация

```sh
npm run build
npm start
```

На хостинге задайте `NUXT_SUPABASE_URL` и `NUXT_SUPABASE_KEY` в окружении или в `.env` рядом с `package.json`. Для доступа с других устройств используйте HTTPS, который нужен браузеру для расшифровки бюджета.

Текущий GitHub Pages обслуживает статические файлы. Для новой версии нужен хостинг с Node.js и маршрутом `/api/budget`. Если сайт открывается из подпапки, задайте `NUXT_APP_BASE_URL` с завершающим слешем, например `/semeyny-byudzhet/`, при сборке и запуске.

При смене адреса сохраните всё после `#` в семейных ссылках. В этой части находится ключ расшифровки, а в некоторых старых ссылках также начальные данные. Для сохранения старых ссылок нужен переход со старого адреса на новый с тем же фрагментом. Кэш браузера привязан к исходному адресу сайта. Если на устройстве есть ещё не отправленные изменения, перед сменой домена синхронизируйте их или скачайте резервную копию.
